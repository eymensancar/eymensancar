よくある質問

機種変更しました。進行状況はどこにありますか？

進行状況はお客様のiCloudにバックアップされています。新しいiPhoneで同じApple アカウントにサインインし、iCloudがオンになっていることを確認してください（設定 → ユーザ名 → iCloud）。ゲームを開けば、前回の続きから遊べます。

購入したアイテムや「広告なし」が消えました。

「ショップ → パック」の一番下にある「購入を復元」をタップしてください。購入内容はApple アカウントに紐づいています。ゴールドパックは消費型アイテムのため復元できません。問題が発生した場合はご連絡ください。

音が出ません。

お好きな音楽を流したまま遊べるよう、本ゲームは着信/サイレントスイッチの設定に従います。サイレントモードをオフにして音量を上げ、ゲーム内の設定でサウンドがオンになっているかもご確認ください。

Game Centerにサインインするには？

「設定 → Game Center」でサインインしてから、ゲームを再起動してください。

自分のデータを削除してほしいです。

当方はお客様のデータを一切収集・保存していません。進行状況はお客様のデバイスとご自身のiCloudアカウントにのみ保存されています。ゲームを削除するとデバイス上のデータは消去され、小さなiCloudバックアップはお客様だけが管理するApple アカウントに残ります。詳しくはプライバシーポリシーをご覧ください。
