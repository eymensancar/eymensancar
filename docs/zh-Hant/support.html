常見問題

我換了新手機，遊戲進度跑去哪了？

你的進度會備份到你的 iCloud。在新的 iPhone 上登入同一個 Apple 帳號，並確認 iCloud 已開啟（設定 → 你的名稱 → iCloud）。打開遊戲，就能從上次停下的地方繼續玩。

我購買的項目或「去廣告」不見了。

到「商店 → 禮包」頁面最下方點一下「回復購買項目」。購買項目會綁定你的 Apple 帳號。金幣禮包屬於消耗性項目，無法回復；如果發生問題，請寫信給我們。

遊戲沒有聲音。

為了讓你可以繼續播放自己的音樂，遊戲會依照響鈴/靜音切換開關的設定。請關閉靜音並調高音量，同時確認遊戲內設定的音效已開啟。

要怎麼登入 Game Center？

到「設定 → Game Center」登入，然後重新啟動遊戲。

我想刪除我的資料。

我們不會蒐集或儲存你的任何資料。你的進度只存在你的裝置和你自己的 iCloud 帳號中；刪除遊戲會移除裝置上的副本，而那份很小的 iCloud 備份會留在只有你本人能管理的 Apple 帳號裡。詳情請參閱隱私權政策。
